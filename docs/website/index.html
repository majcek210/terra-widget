    • What even Terra widget is?

    Terra widget is a desktop application that was developer for the terra project.
    A click thru widget that lives on a corner of your screen and shows your terrra water procentage! After you completed yozr goal it still shows ypu ttoal coding hours.

    Why should I use it?

    For me personaly its the best option to use while coding as then I don't need any websites open to track my progress and the widget is just there.
    Terra tab disconected becaouse you were afk? The widget automaticly reconnects in AFK scenarios.

    Is it safe?

    The widget is completly safe and open source, if you want you can checkput the code yourself! Your session token isn't sent anywhere else than terra. It is stored encrypted if possible only on your your device. But if you leak your token by any chance, rotate your password ASAP

    How do I use it?

    Usage is really straight forward, after you installed the widget(please see the installtion tab) open the program. If your system has Tray support a icon will appear there.
    With a right click on the icon, you can: quit, reconnect and open settings. In case that your system does not have Tray suport, you can open the app again and a setting menu eill be automaticly shown
    In settings you can configure varius settings, such as the widget corner, size, disolay and more. For inital setup please see the token setup part of the installtion

    How it all works

  • Project is written in typescript
  • A custom terra room handler is used make with colyseus sdk
  • The widget itself is made with electron and vite
  • After reciving the data thru SDK, the prigram displays it on HTML
