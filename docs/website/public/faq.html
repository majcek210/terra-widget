FAQ

Here are anwsers for some of the questions you might get.

Why do you need my token?

Token is used to authenticate with terra servers and pull the water data from them as there is no offical way to get data from terra.

Is my token safe?

Yes, token stays on your device and its only sent to terra. If encryption is available, it will be used.

Which devices are supported?

Currently the widget supports windows, linux which is still in its experimental stage and mac which has not been tested and confirmed working as I don't have required devices to test it.
