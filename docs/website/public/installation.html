downloading

Your computer might try to block the file as its unsigned. On windows fix it with right clicking the file in the file explorer, going to properties and then ticking unblock, pressing OK and reopening the app.

Token setup

To get the widget working you have to set up your terra token. You have 2 options.

Automatic login with terra

Just click the login with terra button in settings and login normaly. This works by intercepting the session token after the login and saveing it your device.

Manual login

            Open terra.hackclub.com in your browser and press F12 to open DevTools.
            Go to the Network tab and type exchange in the filter box.
            Log in to Terra (if you're already logged in, log out and back in, the request only shows up on login).
            Click the exchange request and open Response. Copy the value of token, without the quotes.
            Close the Terra tab, otherwise the widget will tell you Terra is open somewhere else.
